# Claude (chat / Cowork / Projects)

Using claude.ai well — separate from the Claude Code CLI.

---

### Chat vs Cowork vs Projects — how to pick

Same model, three ways to use it.

- **Chat** — zero setup, generic output unless you prompt well, context gone when the chat ends. For quick questions and brainstorming.
- **Cowork** (Desktop only) — reads your files, sounds like you, Extended Thinking **on by default**. For deep work sessions, creating real files, long sessions. Context persists as long as you're in the same folder.
- **Projects** — context saved forever across chats. For recurring tasks. Upload files and instructions once; they stick.

The real difference is how context gets in: Chat = paste it every time. Cowork = write `.md` files once and point Claude at the folder. Projects = upload once and it persists.

Both Cowork and Projects need Pro ($20/mo).

**Source:** Ruben Hassid, "How to AI"
**Note:** I live in Cowork. Extended Thinking is on by default there. Projects is better for recurring deliverables like weekly reports.

---

### Always turn on Extended Thinking

It's available on every surface and improves output on anything non-trivial. On by default in Cowork; toggle it on elsewhere.
