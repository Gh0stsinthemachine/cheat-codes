# CLAUDE.md

This repo is a personal knowledge base of tips and tricks for Claude, Claude Code, and web development. It is reference material, not an application.

## What this is

A curated, version-controlled collection of techniques organized as markdown under `tips/`. The owner uses Claude Code and Claude as primary tools for both learning and execution.

## How to help with this repo

- When asked a "how do I…" question about Claude Code, web dev, or the stack, **check `tips/` first** before answering from general knowledge. The answer may already be captured here with the owner's own notes attached.
- When adding a new tip, follow the exact format in `README.md` → "Adding a new tip". Match the existing heading style (`###`), keep entries short, include the command/flag in a code block, and always include a `**Source:**` line.
- Put tips in the right file: Claude Code CLI features → `tips/claude-code.md`; claude.ai surfaces → `tips/claude-ai.md`; recently-shipped features → `tips/whats-new.md`; frontend/backend/infra/payments → `tips/stack.md`; workflows and security → `tips/workflow.md`; Python → `tips/python.md`.
- Keep it sans-serif and clean if any front end is ever added. No serif fonts, ever. Steel Mist palette if styling is needed: `#2F2F2F` charcoal, `#B8C4CC` steel mist, `#EDEAE3` off-white, `#E04540` red.

## Style

Plain, scannable markdown. No marketing fluff. Commands in code blocks. One idea per heading.
